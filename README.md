# Fucking Magnets

How magnets work, told with love for the Juggalo family. One page, eight toys for playing with the math, in English and Thai.

https://nanobotco.github.io/magnets/

- `page.html`: the page, which is also the body of the Claude artifact.
- `tools/build.py`: wraps it into `docs/index.html` and writes the sitemap, robots.txt and llms.txt.
- `tools/card.py`: draws `docs/card.jpg`, the 1200×630 share card.
